# Algorithm Topics Index

Welcome to the algorithm knowledge base. Below is a list of core competitive programming topics covered in this repository. Click on any topic to view detailed explanations, templates, and related problems.

## Index

### Graph Theory
*   [**Graph Theory (Basic)**](Topics/Graph_Theory.md) - Basic concepts of graphs, representations (adjacency list/matrix), and properties.
*   [**Breadth-First Search (BFS)**](Topics/BFS.md) - Traversing graphs level by level; used for shortest paths in unweighted graphs and connected components.
*   [**Bipartite Graph**](Topics/Bipartite_Graph.md) - Checking if a graph is 2-colorable, odd cycle detection, and component counting.
*   [**Graph Structures: Hypercube**](Topics/Hypercube.md) - Properties of $d$-dimensional hypercubes, Hamming distance, and bipartite layering.

### Dynamic Programming
*   [**State Compression DP**](Topics/State_Compression_DP.md) - Used for problems with small state dimensions (e.g., $K \le 10$), often combined with graph structures.
*   [**Moments and Expectation**](Topics/Moments.md) - Techniques for calculating the sum of squares or higher moments of a random variable, usually maintaining `sum1` and `sum2`.

### Mathematics
*   [**Combinatorics**](Topics/Combinatorics.md) - Counting valid configurations, Fibonacci sequences, and parity constraints.
